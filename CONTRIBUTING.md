# Contributing

Thanks for helping improve this AI API provider list.

## What To Submit

Good pull requests usually include one of the following:

- A new AI API provider with public evidence.
- Updated pricing, top-up, payment, model, or support-channel information.
- A correction for stale or misleading provider details.
- Better categorization for OpenAI-compatible, Anthropic-compatible, Claude Code, Codex, Gemini, DeepSeek, or multi-provider API gateway use cases.

## Evidence Required

Please include at least one public source:

- Official website.
- Pricing page.
- Docs page.
- Model list or marketplace page.
- Top-up, subscription, or billing page.
- Official social account or support community.

Screenshots are useful when a page requires login, but avoid publishing secrets, API keys, private user data, or payment details.

## Provider Format

Use the existing table columns:

- Provider.
- Main model families.
- Pricing visibility.
- Minimum top-up.
- Payment methods.

For detailed notes, link to a provider profile on [CCNavX](https://ccnavx.com/) when available.

## Quality Bar

- Keep descriptions factual.
- Avoid marketing claims that cannot be checked.
- Do not add referral links directly to this README.
- Mark uncertain data as "Not listed" instead of guessing.

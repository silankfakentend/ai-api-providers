# Awesome AI API Providers

[简体中文](README.zh-CN.md) | Full directory: [CCNavX AI API Directory](https://ccnavx.com/directory/ai-api-directory)

A curated list of AI API providers, OpenAI-compatible API gateways, Anthropic-compatible API relays, Claude Code API services, Codex API providers, and model aggregation platforms.

This list focuses on practical provider facts: supported model families, public pricing visibility, minimum top-up, and payment methods. The source directory is maintained by [CCNavX](https://ccnavx.com/), a comparison site for AI API proxy services and coding-agent API providers.

## What This List Covers

- OpenAI-compatible API providers for GPT, Codex, and image models.
- Anthropic-compatible API providers for Claude and Claude Code workflows.
- Multi-provider API gateways that aggregate OpenAI, Anthropic, Google Gemini, DeepSeek, xAI, and other model families.
- Developer-focused services with public pricing, top-up credits, subscriptions, payment methods, or support-channel evidence.

## How Providers Are Evaluated

This repository is a curated index, not a paid ranking. A provider may be listed when public evidence is available for at least part of the following:

- Official website or application URL.
- Supported model families or compatible API formats.
- Public pricing page, model marketplace, top-up page, or login-visible billing evidence.
- Payment methods, minimum top-up, subscription plan, or trial-credit information.
- Contact channels, support community, official social account, domain, or certificate verification notes.

For deeper notes, screenshots, pricing context, and multilingual profiles, use the full CCNavX directory:

## 收录标准

这个仓库是精选索引，不是付费排名。一个服务商被收录时，通常需要能公开核验以下部分信息：

- 官网或应用入口。
- 支持的模型家族或兼容 API 格式。
- 公开价格页、模型广场、充值页，或登录后可见的计费证据。
- 支付方式、最低充值、订阅方案或试用额度信息。
- 联系方式、客服社群、官方社媒、域名或证书核验记录。
